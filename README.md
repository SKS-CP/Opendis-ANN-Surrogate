# Surrogate Material Modelling of Plasticity Using a Data-Driven Method

Code and data supporting the manuscript:

> A. Shankar, S. K. Shaw, R. Nayek, S. Chatterjee.
> *Surrogate Material Modelling of Plasticity Using a Data-Driven Method.*
> Submitted to Modelling and Simulation in Materials Science and Engineering.

A data-driven constitutive surrogate trained on three-dimensional Discrete
Dislocation Dynamics (DDD) simulations. The surrogate predicts five independent
components of the plastic rate of deformation tensor **D**ᵖ — the sixth follows
from plastic incompressibility — together with the rate of logarithmic
dislocation-density evolution, in a fully coupled recursive rollout.

A feed-forward network (ANN) and a recurrent network (LSTM) are trained and
compared on the same database under matched supervision.

## Repository structure

| Path | Contents |
|---|---|
| `data/raw/` | Raw OpenDiS output, one CSV per run. See `data/README.md` for the naming convention and column definitions. |
| `data/resampled/` | Runs on the common 1000-point time grid. Generated by `scripts/prepare_data.py`; not tracked in the repository. |
| `scripts/` | Dataset verification, consistency checking and resampling |
| `notebooks/` | Training and evaluation |
| `models/` | Trained ANN and LSTM weights |
| `results/` | Rollout outputs and the metrics reported in the manuscript |
| `figures/` | Scripts that produce the manuscript figures |
| `docs/` | Documentation of the DDD drivers and the surrogate formulation |

## Dataset

68 DDD runs spanning two loading modes, four target stresses, three loading
rates and three initial dislocation densities. Four of the 72 possible
conditions were not run, all at the highest target stress combined with the
lowest loading rate (55 MPa, 4×10⁷ MPa/s): all three shear densities, and
uniaxial at 2.05×10¹² m⁻².

| | Values |
|---|---|
| Loading mode | uniaxial, pure shear |
| Target stress | 30, 40, 50, 55 MPa |
| Loading rate | 4, 6, 8 ×10⁷ MPa/s |
| Initial density | 0.957, 1.43, 2.05 ×10¹² m⁻² |

Runs are split 52 training / 8 validation / 8 test, grouped at run level so
that no run appears in more than one split.

Full documentation of the file naming, units and column definitions is in
[`data/README.md`](data/README.md).

## Reproducing the results

### 1. Verify the database

```
python3 scripts/verify_dataset.py data/raw     # all 68 runs present
python3 scripts/check_data.py data/raw/*.csv   # physics consistency
```

`check_data.py` verifies, for every run, that `trace(Lp) = 0` and that the
recorded equivalent plastic strain rate equals `sqrt(2/3 Dp_dev : Dp_dev)`
computed from the plastic velocity gradient. The first step of each run is
skipped by default: the opening step is dominated by relaxation of the seeded
network, and its trace is looser (~6×10⁻³ relative) than the remainder of the
trajectory (~2×10⁻⁵). Pass `--skip-first 0` to check every step.

### 2. Build the training set

```
python3 scripts/prepare_data.py --raw data/raw --out data/resampled
```

Resamples each run onto the common 1000-point time grid and derives the six
components of `Dp`, `log10(rho)` and `d(log10 rho)/dt`.

### 3. Train and evaluate

Training and rollout are in `notebooks/`. Two supervision modes are provided:

- **Mode A** supplies the true dislocation density and rolls out plastic strain
  only.
- **Mode B** is the fully coupled rollout reported in the manuscript.

## Results

Fully coupled recursive rollout (Mode B), evaluated on the 16 held-out test runs.

| Model | Mean plastic-strain rollout error | Mean density rollout error |
|---|---|---|
| ANN | 7.72% | 2.42% |
| LSTM | 8.53% | 2.07% |
